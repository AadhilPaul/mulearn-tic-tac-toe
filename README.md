# 🎮 μLearn Tic-Tac-Toe

A simple **Tic-Tac-Toe game built with React** as part of a μLearn SNGCE community project.

## ✨ Features

* Two-player Tic-Tac-Toe
* Interactive game board
* Win and draw detection
* Simple responsive interface

## 🛠️ Tech Stack

* React
* Vite
* JavaScript

## 🚀 Getting Started

```bash
git clone <repository-url>
cd mulearn-tic-tac-toe
npm install
npm run dev
```

Then open the local development URL provided by Vite.

## 🎯 Purpose

A small project created as part of the **μLearn SNGCE community initiative**, focused on practicing React and building an interactive browser-based game.
